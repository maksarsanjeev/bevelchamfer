# bevelchamfer

Фаска и скругление рёбер для **SketchUp 2024 / 2025 / 2026**.
Версия **0.2.0**, рабочая сборка для дальнейшей доработки. Исполнение проверено только в **SketchUp 2024 Pro 24.0.484, Ruby 3.2.2**. Проверки в 2025 и 2026 пока не проводились.

Авторы: [maksarsanjeev](https://github.com/maksarsanjeev), [Royalb21](https://github.com/Royalb21). Правообладатель — B&A community. [Apache License 2.0](LICENSE).

## Возможности

- Один сегмент — прямая фаска; несколько — скругление. Размер в мм, режимы «катет» и «радиус».
- Выделение рёбер, граней либо одной группы/компонента целиком.
- Выпуклые и вогнутые рёбра, соединение двух рёбер усом, сферические участки в узлах трёх рёбер.
- Компактная панель: два слайдера, числовые поля по краям и кнопки «Показать» / «Применить». Enter применяет, Esc скрывает превью.
- Параметрическая фаска группы или компонента: исходная сетка и параметры сохраняются внутри SKP. Повторное выделение и возврат фокуса в окно возвращают параметры. «Применить» пересчитывает исходник, пункт «Запечь фаску» контекстного меню сохраняет текущую геометрию и удаляет исходник.
- Защита ручных изменений: при расхождении геометрии пересчёт отказывается затирать правки. Их можно сохранить пунктом «Запечь фаску» контекстного меню.
- Соседние экземпляры компонента не меняются: обрабатываемый экземпляр становится уникальным.
- Материалы лицевой и обратной стороны, теги граней и сквозные отверстия сохраняются. Для новых полос и углов берётся материал одной из прилегающих граней.
- Отмена одним шагом; ошибки размера и потеря замкнутости исходного солида отменяют построение.
- Геометрический движок не использует Pro Boolean / Solid Tools.
- Интерактивная фаска: выбор ребра, грани или вершины мышью, Ctrl/Ctrl+Shift, три щелчка, точный ввод Measurements, повтор размера двойным щелчком, сегменты стрелками 1–24.
- Настоящий Live: отдельный редактируемый исходник и заблокированный результат. Push/Pull и новые рёбра автоматически пересчитывают скругление. Режимы исходник/результат/оба, прозрачность, сглаживание границ, запекание и снятие Live.
- Сглаживание по порогу угла и очистка лишних копланарных рёбер и прямолинейных делений. Настройки применяются сразу, подписи окон доступны на русском и английском.

Полный разбор видео, таймкоды и соответствие реализации: [docs/video-functions.md](docs/video-functions.md).

## Установка

Готовые RBZ **не публикуются** в репозитории и в Releases.

Локальная сборка в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build_rbz.ps1
```

Результат: `build/bevelchamfer0.2.0_test.rbz`. Установить через **Extension Manager → Install Extension**. Для SketchUp 2025/2026 используйте локальный RBZ; скрипт разработки намеренно устанавливает только в 2024:

```powershell
powershell -ExecutionPolicy Bypass -File tools/dev_install.ps1
```

Скрипт сохраняет предыдущую установленную версию в `build/installed-backup-*`. Перезапустите SketchUp после обновления исходников.

## Использование

1. Выделите рёбра/грани или одну группу/компонент. Для выбранного контейнера обрабатываются его непосредственные рёбра.
2. Откройте **Extensions → bevelchamfer → Фаска и скругление** либо нажмите кнопку панели bevelchamfer.
3. Выберите размер и количество сегментов. Число слева задаёт нижний предел и устанавливает текущее значение на этот предел. Ввод справа устанавливает точное значение и верхний предел; при движении слайдера справа показывается текущее значение, а заданный предел сохраняется. Для сегментов минимум — 1.
4. «Показать» включает каркас результата. Пока этот режим активен, изменение параметров обновляет превью. Повторное нажатие («Скрыть») или Esc выключает его. До нажатия «Показать» изменение чисел не включает превью.
5. Нажмите «Применить». Группы/компоненты по умолчанию сохраняют параметры. Для изменения фаски снова выделите объект и вернитесь в окно.
6. Правая кнопка мыши в панели (либо Shift+F10) открывает дополнительные команды: катет/радиус, сохранение параметров, запекание. Для текстур, кривых и вложенных объектов выключите «Сохранить параметры».

## Ограничения рабочей версии

- Только один геометрический контекст за операцию; выбранные контейнеры не обходятся рекурсивно.
- Параметрический режим хранит полигональную сетку без вложенных объектов, кривых, UV-текстур и атрибутов отдельных рёбер/граней. Такие исходники отклоняются с объяснением; можно применить обычную фаску.
- Узлы четырёх и более рёбер, некоторые несферические углы и пересекающиеся подрезки не поддерживаются.
- Неравномерный масштаб и сдвиг осей отклоняются. При равномерном масштабе размер пересчитывается в мировые мм; превью учитывает положение и поворот объекта.
- Нормали исходника должны быть правильно ориентированы. Очень мелкая геометрия ограничена допуском SketchUp 0.001 дюйма; уменьшите сегментацию или увеличьте исходник, если построение отклоняется.
- Материалы сохраняются, но исходная UV-развёртка перестраиваемых граней в обычном режиме не гарантируется.
- Превью сохранённого модификатора вычисляется на временной геометрии с обязательной отменой операции: модель и история Undo сохраняются.

## Проверки

Тесты исполняются **в живом SketchUp 2024**, через локальный мост `POST http://127.0.0.1:8080/ruby/execute`. Каждый запуск проверяет `Sketchup.version` и отказывается работать в другой версии. Виртуальные модели и подмены SketchUp API не используются.

```powershell
powershell -ExecutionPolicy Bypass -File tools/su.ps1 -File test/regression.rb
powershell -ExecutionPolicy Bypass -File tools/su.ps1 -File test/integration.rb
powershell -ExecutionPolicy Bypass -File tools/su.ps1 -File test/holes.rb
powershell -ExecutionPolicy Bypass -File tools/test_su2024.ps1
```

Путь к исходникам определяется относительно тестового файла. Тесты создают собственные группы и удаляют их в `ensure`, не открывают другие пользовательские модели. Проверка сериализации пишет только `build/roundtrip.skp`.

Результаты и отдельная проверка настоящего HtmlDialog описаны в [docs/testing.md](docs/testing.md).
