# Доработанный вариант 03

Геометрически точный изометрический куб со срезанными рёбрами. Прозрачный фон.

- `bevelchamfer-1000.png` — 1000×1000 px.
- `bevelchamfer.svg` — векторный оригинал.
- `bevelchamfer-toolbar.svg` — оптически адаптированный SVG для панели.
- `bevelchamfer-16.png`, `bevelchamfer-24.png` — маленькие иконки SketchUp.
- PNG 32/48 px — дополнительные размеры.

Маленькая версия имеет немного более широкие фаски и усиленные линии, чтобы оставаться читаемой.
