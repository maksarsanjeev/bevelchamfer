# Дизайн-код плагинов B&A community

Единый визуальный язык для HtmlDialog-интерфейсов наших плагинов SketchUp.
Извлечён из RALNCS 0.4; применять в area-counter и следующих плагинах.
Готовые файлы (CSS, JS, шаблон окна, иконки, Ruby-сниппеты) — рядом, см. `README.md`.

## Принципы

1. **Инструмент, не сайт.** Интерфейс похож на панель SketchUp: плотный,
   светлый, без декора, без анимаций ради анимаций. Одна фиксированная
   светлая тема (HtmlDialog не наследует тему ОС — не пытаться).
2. **Одна акцентная кнопка на экран.** Синим выделяется только главное
   действие; всё остальное — нейтральные кнопки.
3. **Цвет несёт смысл.** Цветные элементы — это данные (свотчи, статусы,
   шкалы), а не украшение. Смысловые цвета — из фиксированной палитры ниже.
4. **Русский интерфейс.** Формулировки короткие, без канцелярита. Отказ —
   всегда с причиной («…их перекраска затонировала бы текстуру»), опасное
   действие — через confirm с упоминанием отмены («Действие можно отменить
   (Ctrl+Z)»).
5. **Числа и таблицы — в буфер, не в файлы.** Экспорт делаем TSV + HTML
   (с заливкой ячеек) двумя форматами буфера сразу — вставляется в
   Google Таблицы / Excel готовыми колонками.

## Типографика

- Базовый шрифт: `font: 13px/1.45 "Segoe UI", system-ui, sans-serif;` —
  весь интерфейс, включая кнопки и инпуты (`font: inherit`).
- Вторичные подписи (hex, бейджи, статусы): `11–12px`.
- Заголовки групп: `12px`, `font-weight: 600`, цвет `#666`.
- Кодовые обозначения (RAL 3020 и т.п.): `font-weight: 600`, без моноширинного.

## Каркас окна

Вертикальный flex на всю высоту: **шапка → статусная строка → контент
(скролл) → футер**.

- Шапка: `padding 10px 14px`, фон `#FFF`, нижний бордер `#DDD`,
  `display:flex; gap:10px; align-items:center;` — кнопки действий слева,
  сервисные («Обновить») прижаты вправо через spacer `flex:1`.
- Статусная строка: `padding 6px 14px`, цвет `#666` — счётчики и
  пояснение мелким текстом («Материалов: 202 (…) • ΔE — …»).
- Контент: `flex:1; overflow:auto; padding: 0 14px 14px`.
- Футер-дисклеймер (если нужен): `11px`, `#888`, фон `#FFF`, верхний бордер.

## Компоненты (готовый CSS)

```css
* { box-sizing: border-box; margin: 0; padding: 0; }
body {
  font: 13px/1.45 "Segoe UI", system-ui, sans-serif;
  color: #1c1c1c; background: #f5f5f4;
  display: flex; flex-direction: column; height: 100vh;
}

/* Кнопки */
button {
  font: inherit; padding: 6px 12px; border: 1px solid #bbb;
  border-radius: 6px; background: #fff; cursor: pointer;
}
button:hover { background: #f0f0ef; }
button.primary { background: #2b6cb0; border-color: #2b6cb0; color: #fff; }
button.primary:hover { background: #245a94; }
button:disabled { opacity: .4; cursor: default; }

/* Вкладки — те же кнопки, активная закрашена акцентом */
.tab.on { background: #2b6cb0; border-color: #2b6cb0; color: #fff; }

/* Поле ввода / поиск */
input[type="search"], input[type="text"] {
  font: inherit; padding: 6px 10px; border: 1px solid #bbb; border-radius: 6px;
}

/* Таблица данных */
table { border-collapse: collapse; width: 100%; background: #fff; }
th, td { padding: 6px 8px; border-bottom: 1px solid #eee; text-align: left; white-space: nowrap; }
th { position: sticky; top: 0; background: #fafaf9; border-bottom: 1px solid #ddd; z-index: 1; }

/* Свотч цвета (в строке таблицы) */
.sw {
  display: inline-block; width: 22px; height: 22px; border-radius: 4px;
  border: 1px solid rgba(0,0,0,.2); vertical-align: middle; margin-right: 7px;
}
/* Ячейка сетки-палитры: 27px, radius 5px, hover — рамка акцентом */
.cell { width: 27px; height: 27px; border-radius: 5px; border: 1px solid rgba(0,0,0,.15); cursor: pointer; }
.cell:hover { outline: 2px solid #2b6cb0; outline-offset: 1px; }
.cell.sel { outline: 3px solid #1c1c1c; outline-offset: 1px; }

/* Бейджи-таблетки: цветные — статус, серый — свойство */
.pill { display: inline-block; padding: 1px 7px; border-radius: 10px; font-size: 11px; color: #fff; }
.pill.ok    { background: #2f855a; }
.pill.good  { background: #68a63e; }
.pill.warn  { background: #dd8a20; }
.pill.bad   { background: #c53030; }
.pill.neutral {
  background: #ececea; color: #777; border: 1px solid #ddd;
}

/* Тост — единственная «анимация» в интерфейсе */
#toast {
  position: fixed; bottom: 16px; left: 50%; transform: translateX(-50%);
  background: #1c1c1c; color: #fff; padding: 8px 16px; border-radius: 8px;
  opacity: 0; transition: opacity .25s; pointer-events: none;
}
#toast.on { opacity: .92; }
```

Правила поверх CSS:

- Скругления: кнопки/инпуты 6px, свотчи 4–5px, карточки/тосты 8px,
  таблетки 10px. Ничего круглее.
- Тени не используем — только бордеры.
- Выделение выбранного: `outline` (2px акцент на hover, 3px `#1c1c1c` на
  выборе), не смена фона.

## Иконки тулбара

- Flat SVG, `viewBox="0 0 24 24"`, только заливки и простые обводки —
  без градиентов, текста и фильтров (ограничения SketchUp).
- Палитра иконки — смысловые цвета выше (`#C1121F`, `#F2A900`, `#2F855A`,
  `#2B6CB0`) + тёмный `#3B3B38` для обводок и «железа».
- Обводка контура: `1.6`, скругления элементов `rx` 0.85–2.2.
- Один и тот же файл для `small_icon` и `large_icon`.
- Сюжет иконки — предмет из жизни архитектора (веер цветов, лист ТЗ),
  не абстрактная пиктограмма.

## Паттерны поведения

- **Тост вместо alert** для подтверждений и мягких отказов (2–2.2 с).
- **confirm() перед изменением модели**, в тексте: сколько объектов
  затронется, что будет пропущено и почему, «Действие можно отменить (Ctrl+Z)».
- Само изменение — одной операцией `model.start_operation … commit_operation`,
  чтобы Ctrl+Z снимал всё разом.
- Чекбокс «все» в шапке + чекбоксы строк; кнопки действий работают
  с выбранными.
- **Настройка столбцов** — кнопка «Столбцы ▾» справа в шапке открывает
  попап-панель (абсолютно под шапкой, `border-radius 8px`, бордер `#CCC`):
  группы с чекбоксом и ▲▼, внутри — столбцы с чекбоксом и ▲▼; внизу
  подсказка мелким серым и «Сбросить». Экранная таблица и экспорт строятся
  из одного списка видимых столбцов. Настройка хранится через
  `Sketchup.write_default` компактной строкой без кавычек
  (`mat:name,-rgb|-ral:...`) — JSON в реестре ломается.
- Таблица с группами столбцов — двухуровневая sticky-шапка: строка групп
  (11px, uppercase, `#888`, высота 24px) и строка столбцов (`top: 24px`).
  Группы отделены левым бордером `#E4E4E2` в шапке и `#F0F0EE` в строках.
- Рискованные опции (например, «тонировать текстурные») — выключены по
  умолчанию, включаются явной галочкой рядом с кнопками действия; текст
  confirm меняется в зависимости от галочки.
- Копирование в буфер: `navigator.clipboard.write` (ClipboardItem,
  text/plain + text/html) с фолбэком на textarea + `execCommand('copy')`
  и перехватом события copy.
- Данные в диалог передаём после колбэка `ready` через
  `dialog.execute_script("init(<json>)")` — не через file:// fetch.
- Тултипы (`title=`) на всём, что усечено или закодировано цветом.

## Тексты

- Кнопки — глаголом: «Скопировать ТЗ», «Применить RAL», «Создать и красить».
- Статусы — счётчик + расшифровка: «Материалов: 202 (однотонных 119,
  текстурных 83)».
- Единицы и коды пишем как в отрасли: `RAL 3020`, `NCS S 1010-Y90R`,
  RGB через дефис `240-211-208`.
- Дисклеймеры честные: «Цвета показаны в sRGB-приближении… финальное
  решение сверяйте с физическим веером».
